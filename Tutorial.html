Langkah 1: Persiapan Aplikasi (Tools)

Sebelum mulai menulis kode program, persiapkan dua aplikasi utama berikut:

  • Text Editor: Gunakan Visual Studio Code (VS Code) untuk mengetik kode HTML dan CSS.
  • Web Browser: Gunakan Google Chrome atau Microsoft Edge untuk melihat hasil halaman web Anda.

Langkah 3: Penjelasan Tag Penting

Berikut fungsi dari atribut dan tag yang sering digunakan dalam pembuatan layout tabel:

Tag / Atribut Fungsi Utama
<table> Membentuk kerangka utama tabel di halaman web.
<tr> (Table Row) Membuat baris baru secara horizontal di dalam tabel.
<td> (Table Data) Membuat kolom atau sel di dalam baris tempat memasukkan teks/gambar.
width="100%" Membuat ukuran lebar tabel membentang penuh menyesuaikan layar.
cellpadding="..." Atur jarak antara garis sel dengan teks di dalamnya agar terlihat lebih lega.
